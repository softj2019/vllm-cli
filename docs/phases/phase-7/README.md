# Phase 7 — Ops Runbook & Handover

## Objective

운영팀이 독립적으로 장애 대응/업그레이드 가능한 수준으로 인수인계를 완료한다.

## Scope

- 일일 점검표
- 장애 대응 절차
- 업그레이드/모델 교체 절차

## Detailed Tasks

1. Runbook 작성(기동, 중지, 로그, 헬스체크)
2. 장애 유형별 대응표 작성
3. 모델 교체 SOP 작성
4. 온콜 체크리스트 작성
5. 인수인계 리허설(질의응답) 수행

## Deliverables

- 운영 Runbook
- 장애 대응 매트릭스
- 인수인계 완료 체크리스트

## Exit Criteria

- 운영자 단독으로 기동/복구/롤백 성공
- 미해결 P1/P2 이슈 0

## Risks

- 문서와 실제 운영 절차 괴리
- 지식 편중(특정 인원 의존)
